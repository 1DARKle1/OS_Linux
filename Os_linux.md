# Конспект: Администрирование Linux

## Тема 2. Администрирование Linux

### SUID, SGID и Sticky Bit

В Linux существуют файлы и программы, которые принадлежат пользователю
`root`, но при этом обычным пользователям нужно иметь возможность их
запускать. Для этого используются специальные права доступа: **SUID**,
**SGID** и **Sticky Bit**.

### SUID (Set User Identifier)

**SUID** позволяет при запуске файла временно получить права его
владельца.

Например, если файл принадлежит `root` и имеет установленный SUID,
обычный пользователь при запуске этого файла может выполнять его с
правами владельца файла.

### SGID (Set Group Identifier)

**SGID (Set Group Identifier)** похож на SUID, но работает с группой.

SGID устанавливает права группы-владельца файла. Также файлы,
создаваемые внутри каталога с установленным SGID, получают идентификатор
группы-владельца этого каталога.

### Sticky Bit

**Sticky Bit** используется в каталогах и ограничивает удаление файлов.

Если Sticky Bit установлен, пользователь может удалить файл только в том
случае, если он: - является владельцем файла; - или является владельцем
каталога, в котором находится файл.

Это часто используется в общих каталогах, где несколько пользователей
могут создавать файлы.

## Umask

**Umask** определяет, какие права доступа будут убраны из первоначальных
прав нового файла или каталога.

При создании файла система сначала использует стандартные права, а затем
применяет значение `umask`.

Например:

``` bash
umask
```

может показать:

``` text
0022
```

Проверить значение в более понятном символьном виде можно командой:

``` bash
umask -S
```

Пример результата:

``` text
u=rwx,g=rx,o=rx
```

В Linux значение `umask` по умолчанию часто равно `0022`.

## Переключение пользователя

### Команда `su`

`su` (switch user) позволяет перейти на другого пользователя, например
на `root`, если известен пароль этого пользователя.

Пример:

``` bash
su
```

или:

``` bash
su имя_пользователя
```

После выполнения команды можно работать от имени выбранного
пользователя.

------------------------------------------------------------------------

## Sudo

**sudo** позволяет обычному пользователю выполнять отдельные команды с
правами суперпользователя, не создавая новую оболочку.

Чтобы пользователь мог использовать `sudo`, его обычно добавляют в
группу `sudo`:

``` bash
usermod -aG sudo имя_пользователя
```

После этого пользователь получает возможность выполнять разрешённые
команды через `sudo`.

Пример:

``` bash
sudo команда
```

Главное отличие от `su`: `sudo` предназначен для выполнения отдельных
команд с повышенными правами, а `su` позволяет переключиться на другого
пользователя.

------------------------------------------------------------------------

## Sudoers

Файл **sudoers** содержит список пользователей и правила, определяющие,
какие команды они могут выполнять через `sudo`.

Редактировать настройки рекомендуется командой:

``` bash
visudo
```

Она позволяет безопасно изменить конфигурацию `sudo`.

Пример строки:

``` text
root ALL=(ALL:ALL) ALL
```

Она означает, что пользователь `root` имеет неограниченные права.

Другой пример:

``` text
%sudo ALL=(ALL:ALL) ALL
```

Здесь `%sudo` означает группу `sudo`. Пользователи этой группы получают
право выполнять любые команды через `sudo`, если это правило
присутствует в конфигурации.

------------------------------------------------------------------------

## Строка привилегий

Пример:

``` text
root ALL=(ALL:ALL) ALL
```

Эта строка состоит из нескольких частей:

-   **root** --- имя пользователя;
-   первое **ALL** --- правило применяется ко всем хостам;
-   **(ALL:ALL)** --- пользователь может выполнять команды от имени
    любых пользователей и групп;
-   последнее **ALL** --- разрешены все команды.

Таким образом, строка:

``` text
root ALL=(ALL:ALL) ALL
```

означает, что `root` имеет право выполнять любые команды с любыми
пользовательскими и групповыми правами.

## Кратко

-   **SUID** --- запуск файла с правами его владельца.
-   **SGID** --- работа с правами группы-владельца.
-   **Sticky Bit** --- ограничивает удаление файлов в общем каталоге.
-   **umask** --- определяет, какие права будут убраны при создании
    новых файлов и каталогов.
-   **su** --- переключение на другого пользователя.
-   **sudo** --- выполнение отдельных команд с повышенными правами.
-   **sudoers** --- настройки разрешений для `sudo`.
