# OS Linux

Репозиторий по курсу GNU/Linux.

## Папки

- `теория` - конспекты
- `практика` - скрипты с занятий
- `домашка` - готовые задания

## теория

- `vvedenie-gnu-linux.md` - введение в GNU/Linux
- `planirovanie-processov.md` - планирование процессов
- `Os_linux.md` - общий конспект
- `Linux_Admin` - администрирование
- `README.md` - что такое дистрибутив и из чего он собран

## практика

- `bash20` - двадцать базовых скриптов
- `ошибки` - обработка ошибок в bash
- `working with conditions, loops, and functions` - условия, циклы и функции

## домашка

- `dz-skript` - те же 20 скриптов, оформленные как сдача
- `usloviya-cikly-funkcii` - условия, циклы и функции
- `pamyat` - скрины по памяти процесса
- `processy` - скрины по процессам, сигналам и top
