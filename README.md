# Linux

Linux - это операционная система, основанная на ядре Linux и программном обеспечении GNU, предназначенная для установки на пользовательское оборудование.
GNU - Это набор системных утилит и программ, созданный проектом GNU (GNUs Not Unix) в 1984 году Ричардом Столлманом
В GNU входят: компилятор GCC, текстовый редактор Emacs, шелл Bash

## Пункты и их определения:

### 1. Дистрибутив GNU/Linux 
 Это набор программного обеспечения, включающий ядро Linux, библиотеки, утилиты, графическую среду и документацию, собранный в единый пакет для установки и использования на компьютере.

### 2 Ядро Linux 
 Основной компонент операционной системы, обеспечивающий управление аппаратными ресурсами и выполнение программ.

### 3. Набор библиотек и утилит, выпускаемых в рамках проекта GNU 
 это набор программных компонентов, обеспечивающих выполнение различных функций и интерфейсов для работы с системой, разработанных проектом GNU.

### 4. Графическая подсистема X Window System (Wayland) 
 Это программная система, обеспечивающая отображение графического интерфейса пользователя на экране. X Window System - классическая реализация, а Wayland - современная альтернатива.

### 5. Графическое окружение рабочего стола 
 Интерфейс пользователя, включающий окна, меню, панели и другие элементы, обеспечивающие взаимодействие с системой.

### 6. Документация к системе
 Инструкции, руководства и справочные материалы, помогающие пользователю понять и эффективно использовать систему.

### 7. Набор приложений, таких как редакторы документов и таблиц, мультимедийные проигрыватели, системы для работы с базами данных и т.д.
 это дополнительное программное обеспечение, расширяющее возможности системы для выполнения различных задач.

### 8. Программы, распространяемые на условиях собственнических лицензий (драйвера, кодеки) 
 это платное или закрытое программное обеспечение, используемое для расширения функциональности системы, например, драйверы устройств или мультимедийные кодеки.


# Дистрибутивы GNU/Linux

## Основные пункты

### 1. Разнообразие дистрибутивов
На сегодняшний день существует более 600 дистрибутивов GNU/Linux. Более половины из них поддерживаются в актуальном состоянии благодаря регулярным обновлениям, которые предоставляются разработчиками.

**Что это означает:**  
Пользователи имеют широкий выбор дистрибутивов, и большинство из них активно обновляется для обеспечения безопасности и новых возможностей.

### 2. Типы поддержки дистрибутивов
Некоторые дистрибутивы разрабатываются и поддерживаются коммерческими компаниями (например, Red Hat / Fedora, openSUSE, Ubuntu), а другие создаются и поддерживаются сообществом добровольцев (например, Debian, Slackware, Gentoo, Arch Linux).

**Что это означает:**  
Выбор может зависеть от того, предпочитаете ли вы коммерческую поддержку или свободное сообщество, предоставляющее более свободные условия использования и настройки.

### 3. Установка и сборка программного обеспечения
Многие дистрибутивы включают систему установки, которая выполняет функции, аналогичные другим современным операционным системам.  

Некоторые дистрибутивы, такие как Gentoo и Arch Linux, содержат только ядро и инструменты для сборки программного обеспечения, а также собственный установщик, который собирает всё необходимое под архитектуру вашего устройства.

**Что это означает:****  
В таких системах пользователь имеет возможность максимально настроить свою ОС под свои нужды, собирая компоненты отдельно и оптимизируя систему под аппаратные особенности.


# Идентификаторы файлов (inode или индексный дескриптор)

Идентификаторы (inode или индексный дескриптор) предназначены для хранения метаданных о файлах, каталогах и других объектах файловой системы.

## Основные моменты

### 1. Связь между именами и inode
Имена файлов (или каталогов) в файловой системе связаны с inode, который содержит метаданные файла.  
**Процесс:**  
- Имя файла > inode > физические данные на диске.

### 2. Уникальность inode
Каждый файл в каталоге GNU/Linux имеет имя и уникальный номер inode.  
Пользователь может получить метаданные файла, указав его номер inode.

### 3. Уникальность inode
Inodes являются уникальными в пределах одного раздела диска.  
Можно иметь два файла с одинаковым номером inode, если они находятся в разных разделах.

### 4. Количество inodes
Количество inode в файловой системе определяется при её создании. Это число не меняется после форматирования.

### 5. Атрибуты inode
Обычно каждый inode содержит следующие атрибуты:
- Размер файла
- Владелец
- Дата и время последнего изменения
- Разрешения доступа и контроль доступа
- Расположение данных на диске
- Тип файла (обычный файл, каталог, символьная ссылка и т.д.)
- Количество ссылок (количество путей, ведущих к файлу)
- Дополнительные метаданные, связанные с файлом
