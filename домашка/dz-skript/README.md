# Скрипты

20 заданий из файла «ДЗ скрипт».

Запуск: `chmod +x имя.sh` и затем `./имя.sh`.

## Задача 2

`./check.sh` печатает OK.

Без `./` оболочка ищет `check.sh` только в каталогах из PATH. Текущая папка в PATH не входит, поэтому команда не находится.

## Задача 3

`script.sh` начинается с `#!/usr/bin/env bash`.

- `./script.sh` читает shebang и запускает bash.
- `bash script.sh` сразу вызывает bash, shebang для этого не нужен.
- `sh script.sh` на Debian и Ubuntu часто вызывает dash. Строка `words=(один два)` в dash не работает, скрипт останавливается с ошибкой.

## Задача 4

```bash
chmod 700 perm.sh
./perm.sh
```

`ls -l` покажет права `rwx------`: читать, писать и запускать может только владелец.

## Задача 12

Без `export` дочерний `bash -c` не видит `MYVAR`, строка пустая.

После `export` переменная попадает в окружение, дочерний bash печатает `secret`.
