# Введение в GNU/Linux

## GNU и ядро

GNU (GNU's Not Unix) - проект свободного ПО. Манифест написал Ричард Столмен в 1985 году. Цель: чтобы можно было работать без проприетарных программ. Формально это сложилось в 1992 году, когда появилось ядро Linux.

Linux - это ядро. Оно раздает ресурсы машины программам, которые запускает пользователь. Само по себе ядро бесполезно, ему нужна остальная система. Обычно его ставят вместе с утилитами GNU. Такую связку называют GNU/Linux. «Дистрибутив Linux» на практике и есть GNU с ядром Linux.

## Из чего состоит дистрибутив

Готовая система для установки на компьютер:

- ядро Linux
- библиотеки и утилиты GNU
- графика: X Window System или Wayland, плюс окружение рабочего стола
- документация
- прикладные программы: редакторы, плееры, базы данных

Внутри могут быть и закрытые программы: драйверы, кодеки. Дистрибутивов больше шестисот, больше половины еще обновляют. Каталог: distrowatch.com.

Коммерческие: Red Hat / Fedora, OpenSUSE, Ubuntu. Силами сообщества: Debian, Slackware, Gentoo, Arch Linux. У Gentoo и Arch при установке часто собирают софт под свою машину, в комплекте ядро, сборщик и установщик.

## Основные дистрибутивы

- Debian. С 16 августа 1993 года, собран с нуля. Один из самых старых и стабильных. Релиз примерно раз в 2 года. Больше 59 000 пакетов.
- Ubuntu. Самый популярный, основан на Debian. Делает Canonical. Релизы в апреле и октябре. Есть версии для ПК и серверов. Основная оболочка Gnome, еще Kubuntu и Xubuntu.
- Linux Mint. Для дома, основан на Ubuntu, релизы 2 раза в год. Оболочка Cinnamon похожа на Windows. Еще есть Mate и Xfce.
- Arch Linux. Минимальная база, пользователь сам ставит нужное. Официально около 11 000 пакетов, в AUR около 54 000. AUR ведет сообщество, там свежие версии в исходниках. Модель rolling release: система обновляется постоянно, без больших редких релизов.
- Manjaro. На базе Arch, оболочки KDE, Xfce, Gnome и другие. Есть доступ к AUR, обновления регулярные.
- Red Hat Enterprise Linux. Коммерческий, от Red Hat. Платная поддержка и быстрые важные обновления. Fedora - свободный полигон для обкатки. CentOS раньше был бесплатной копией RHEL, над ними работает одна команда. Дальше CentOS 8 и CentOS Stream.
- Fedora. Свободный, на базе Red Hat Linux. Есть Fedora Workstation и Fedora Server. Базовая оболочка Gnome.
- openSUSE. От Slackware. Обновление раз в год, долгая поддержка. На сайте можно собрать свой набор программ. Подходит и для дома, и для работы.

## Файлы и inode

Имя файла в каталоге указывает на inode, а inode указывает на данные на диске.

Inode - индексный дескриптор. В нем метаданные, не само содержимое:

- размер
- владелец
- дата и время
- права доступа
- где лежит на диске
- тип файла
- число ссылок

Номер inode уникален внутри одного раздела. На разных разделах одинаковые номера возможны. Сколько inode будет у файловой системы, задают при ее создании.

## Конфигурация

- `/etc/hostname` - имя компьютера
- `/etc/sysconfig/` - настройки системы
- `/etc/ssh/` - сервер SSH
- `$HOME/.ssh/config` - SSH этого пользователя
- `/etc/resolv.conf` - DNS
- `/etc/hosts` - локальные имена узлов
- `/etc/os-release` - название и версия дистрибутива
- `/etc/passwd` - список пользователей
- `/etc/group` - группы
- `/etc/shadow` - хеши паролей
- `/etc/sudoers` - кому можно sudo
- `/etc/environment` - переменные окружения, в том числе PATH
- `/etc/fstab` - что и куда монтировать при загрузке
- `/etc/default/grub` - настройки, из которых `update-grub` собирает `/boot/grub/grub.cfg`
- `/etc/crontab` - планировщик заданий

## Журналы

Каталог `/var/log/`.

- `syslog` или `messages` - общий журнал с момента запуска
- `auth.log` или `secure` - входы в систему, удачные и нет
- `dmesg` - драйверы устройств
- `boot.log` - загрузка
- `cron` - задания cron
- `faillog` - неудачные входы
- `kern.log` - сообщения ядра
- `maillog` или `mail.log` - почта
- `samba/` - Samba
- `yum.log` - пакеты yum
- `mysql/` - база MySQL
- `httpd/` или `apache2/` - веб-сервер Apache: `access_log` это обращения, `error_log` это ошибки

Смотреть журнал: `less /var/log/maillog`. Следить за новыми строками: `tail -f /var/log/maillog`.

Справка по команде: `man tail`. Справка по самой справке: `man man`.
